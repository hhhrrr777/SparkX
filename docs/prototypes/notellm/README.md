# NoteLLM 视觉原型 A（待用户确认）

对应[确认 NoteLLM 全站导航与视觉原型](https://github.com/hhhrrr777/SparkX/issues/5)。用户选择第 1 张生成图作为目标；这是一次性原型，不应直接合并为正式实现。

## 运行

在仓库 admin 目录安装现有依赖后运行 `npm run prototype`，打开 `http://127.0.0.1:4173/notellm-prototype.html?variant=A`。

`npm run prototype:build` 可检查独立原型构建；原型不进入正式应用入口，正式构建不会自动包含它。

代码位于 `admin/src/views/chat/notellm-prototype/`，使用项目现有 Vue/Vite 与 Ionicons 依赖。选择独立入口，是因为本次替换整个应用壳层，需在不连接鉴权和业务 API 的情况下演示导航与写入反馈；没有改变正式应用路由或权限。

## 目标与待确认规则

- 视觉：以 selected-reference.png 为准，浅色默认，青蓝单强调色，灰底白面板、细分隔线；原创折纸 N 标识。
- 字体：系统 sans（macOS PingFang SC，其他平台 Microsoft YaHei 等回退），正文 14–16px、首页主标题 34px、管理页标题 27px。
- 桌面侧栏约 294px，主体上/右边距 24px、圆角 20px；输入区上限约 860px。低于 1100px 缩窄侧栏，760px 及以下切换顶部栏+抽屉。
- 聊天空态输入区居中，会话态输入区固定于消息区域底部；来源点击后打开右侧抽屉，手机全宽。聊天设置和智能体选择按需展开。
- 知识库使用列表，文件详情使用有明确状态的表格，区分处理中/可检索/失败；失败可重试，文件可搜索，空结果可见。
- 智能体保留独立业务入口、创建/配置及测试对话路径。工作流保留独立入口，外围统一样式，节点配置在侧面板；正式画布沿用现有能力。
- 设置独立分组：模型配置、解析引擎、MCP 服务、意图路由、样例查询、知识图谱、外观。帮助和账户保留低频入口，正式实现仍按原权限显示。
- 深色使用语义 token 替换背景/文字/边框；本原型已展示浅深主题，尚待用户确认首选仍为浅色。
- 登录/错误页未来沿用同一品牌和 token；本原型未逐页实现。现有知识库高级操作、Agent 评估和工作流运行详情等需保留能力，原型不会替代这些功能的业务规格。
- 原版权通知按已确认的品牌边界保留；文档帮助链接仍指向现有仓库地址。

## 交互边界

所有数据是固定样例或内存数据，刷新重置。附件只读取文件名与大小，文件不会上传；无 AI 请求、数据库或外部服务连接。模拟结果不会作为真实业务结果。创建可新增演示项，设置/节点保存仅展示反馈，不是生产持久化。文件详情使用统一样例数据，不用于判断真实库内容。

工作流为结构/交互示意，图谱等设置是入口与样式示例；不据此删减原有业务能力。手机画布保留局部水平滚动，复杂编辑桌面优先；软键盘及真实设备仍需正式实现时验证。
